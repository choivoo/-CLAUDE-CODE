# 쿠키런 스타일 러닝 게임 (HTML5) 기획서

> 목표: 브라우저에서 바로 실행되는 횡스크롤 자동 달리기(Endless Runner) 게임을 HTML5 Canvas + JavaScript로 제작한다.
> 참고 장르: 「쿠키런: 오븐브레이크」류의 점프/슬라이드 러너.
> **저작권 주의:** '쿠키런'과 캐릭터(용감한 쿠키 등)는 데브시스터즈의 상표/저작물이다. 본 프로젝트는 **장르 학습·팬 프로젝트 목적**이며, 캐릭터·이미지·음원은 **직접 제작한 오리지널 에셋**(또는 CC0)을 사용한다. 배포 시 명칭도 변경한다(가칭: **"쿠키 대탈출"**).

---

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 장르 | 2D 횡스크롤 자동 달리기 (Endless Runner) |
| 플랫폼 | PC/모바일 웹 브라우저 (HTML5 Canvas) |
| 기술 스택 | HTML + CSS + Vanilla JS (빌드 도구 없음, 단일 폴더 배포) |
| 플레이 타임 | 1판 1~3분, 반복 플레이형 |
| 목표 | 장애물을 피하고 젤리를 모아 최고 점수 갱신, 에너지(HP)가 0이 되면 종료 |
| 핵심 재미 | 단순 조작(점프/슬라이드) + 점점 빨라지는 속도 + 아이템 콤보의 쾌감 |

### 세계관 (오리지널 설정)
오븐 속에 갇힌 쿠키가 마녀의 오븐 성에서 탈출하기 위해 달린다. 달릴수록 에너지가 줄어들고, 젤리를 먹으면 회복·점수 획득.

---

## 2. 게임 특징

1. **자동 달리기**: 캐릭터는 항상 오른쪽으로 달리며 플레이어는 점프/슬라이드만 조작.
2. **에너지(HP) 시스템**: 시간이 지나면 에너지 서서히 감소, 장애물 충돌 시 크게 감소, 회복 아이템으로 보충.
3. **젤리 수집**: 기본 젤리(점수), 큰 젤리(고득점), 코인(재화).
4. **파워업 아이템**: 자석(젤리 흡수), 부스터(무적 질주), 거대화(장애물 파괴), 에너지 포션.
5. **더블 점프**: 공중에서 한 번 더 점프 가능.
6. **난이도 곡선**: 거리가 늘수록 속도 증가, 장애물 패턴 복잡화.
7. **패턴 기반 맵 생성**: 미리 설계한 구간(패턴)을 랜덤 조합하여 무한 맵 구성.
8. **로컬 랭킹**: `localStorage`에 최고 점수/코인 저장.

## 3. 디자인 특성

### 3.1 아트 스타일
- 밝고 귀여운 **카툰풍 2D**, 두꺼운 외곽선(2~3px), 파스텔 + 고채도 포인트 컬러.
- 캐릭터는 2~3등신 SD 비율, 큰 눈, 단순한 형태 → 작은 화면에서도 식별 용이.
- 모든 사물은 "과자/디저트" 모티프 (젤리, 사탕, 쿠키, 케이크, 초콜릿).

### 3.2 컬러 팔레트
| 용도 | 색상 |
|---|---|
| 하늘/배경 | `#8FD3FF`, `#FFE9B8` |
| 지면(초코/쿠키) | `#8B5A2B`, `#C68642` |
| 강조(젤리/버튼) | `#FF6FA5`, `#FFD23F`, `#5BD16B` |
| UI 텍스트 | `#FFFFFF` + `#5A3A22` 외곽선 |
| 위험(장애물/HP 경고) | `#E8453C` |

### 3.3 폰트·연출
- 폰트: 둥근 고딕 계열 (예: Jua, Gaegu — Google Fonts, 무료).
- 이펙트: 점프 먼지, 젤리 획득 반짝임, 피격 시 화면 흔들림 + 깜빡임(무적 1.5초).
- 사운드: BGM 1곡(루프) + 효과음(점프, 슬라이드, 젤리, 피격, 아이템, 게임오버).

## 4. UI 구성

### 4.1 화면 흐름
```
[로딩] → [타이틀] → [캐릭터 선택(선택)] → [인게임] ⇄ [일시정지]
                                              ↓
                                         [결과 화면] → [다시하기/타이틀]
```

### 4.2 타이틀 화면
- 로고, "게임 시작" 버튼, "도움말" 버튼, 최고 점수 표시, 사운드 ON/OFF 토글.

### 4.3 인게임 HUD (해상도 기준 1280×720, 반응형 스케일)
```
┌──────────────────────────────────────────────┐
│ [♥ HP 바 ████████░░]      점수 000,000  🪙 123 │ ← 상단
│                                   [⏸ 일시정지] │
│                                              │
│            (게임 플레이 영역)                   │
│                                              │
│ [슬라이드 버튼]                  [점프 버튼]    │ ← 모바일 터치 영역
└──────────────────────────────────────────────┘
```
- 좌상단: HP 바 (30% 이하 시 빨간색 점멸)
- 우상단: 점수 / 코인 / 일시정지
- 하단 좌·우: 모바일용 터치 버튼(화면 좌/우 절반 터치로 대체 가능)
- 활성 파워업 아이콘 + 남은 시간 게이지

### 4.4 결과 화면
- 최종 점수, 달린 거리, 획득 젤리/코인, 신기록 표시, "다시하기" / "타이틀" 버튼.

## 5. 캐릭터

### 5.1 플레이어 캐릭터 (오리지널)
| 이름(가칭) | 컨셉 | 특성 |
|---|---|---|
| 진저 (기본) | 용감한 진저브레드 쿠키 | 균형형, 더블 점프 |
| 베리 | 딸기맛 쿠키 | 젤리 획득 범위 +20% |
| 초코 | 초코칩 쿠키 | 피격 데미지 -15% |

- 스프라이트 상태: `달리기(6프레임)`, `점프`, `더블점프`, `슬라이드(3프레임)`, `피격`, `사망`.
- 충돌 박스(히트박스)는 이미지보다 약간 작게 설정(관대한 판정 → 재미 향상).

### 5.2 장애물·적
| 종류 | 설명 | 회피 방법 |
|---|---|---|
| 가시 (바닥) | 지면 가시 | 점프 |
| 낮은 장벽 | 낮은 사탕 울타리 | 점프 |
| 공중 장애물 | 날아다니는 박쥐 사탕 | 슬라이드 |
| 구멍(낭떠러지) | 바닥이 없는 구간 | 점프/더블점프 |
| 이동 장애물 | 위아래로 움직이는 톱니 | 타이밍 |

### 5.3 아이템
| 아이템 | 효과 | 지속 |
|---|---|---|
| 일반 젤리 | +100점 | - |
| 큰 젤리 | +500점 | - |
| 코인 | 재화 +1 | - |
| 에너지 포션 | HP +30% | - |
| 자석 | 주변 젤리 흡수 | 6초 |
| 부스터 | 무적 + 속도 증가 + 젤리 자동획득 | 4초 |
| 거대화 | 크기 2배, 장애물 파괴 | 5초 |

## 6. 배경(스테이지)

### 6.1 패럴랙스 레이어 구성
1. 하늘 (고정, 그라데이션)
2. 원경 (구름/산, 속도 0.1x)
3. 중경 (나무/건물, 속도 0.3x)
4. 지면 + 장애물 (속도 1.0x)
5. 전경 장식 (속도 1.3x, 선택)

### 6.2 스테이지 테마 (거리 기준 전환)
| 구간 | 테마 | 분위기 |
|---|---|---|
| 0~1,000m | 쿠키 마을 | 밝은 낮, 쿠키 집·캔디 나무 |
| 1,000~2,500m | 초콜릿 강 | 갈색·핑크 톤, 초콜릿 폭포 |
| 2,500m~ | 마녀의 오븐 성 | 어두운 보라·붉은 톤, 불꽃 |

- 테마 전환 시 배경 이미지를 크로스페이드하여 자연스럽게 연결.

## 7. 조작법

| 동작 | PC (키보드) | 모바일 (터치) |
|---|---|---|
| 점프 | `Space` / `↑` / `W` | 화면 우측 터치 |
| 더블 점프 | 공중에서 점프 키 재입력 | 공중에서 우측 재터치 |
| 슬라이드 | `↓` / `S` (누르는 동안 유지) | 화면 좌측 터치 (누르는 동안 유지) |
| 일시정지 | `P` / `Esc` | 일시정지 버튼 |
| 확인/시작 | `Enter` / 클릭 | 터치 |

- 점프 높이: 키를 짧게/길게 누르는 정도에 따라 가변 점프(선택 사항).
- 입력 버퍼링(착지 직전 입력 0.1초 허용) + 코요테 타임(낭떠러지 끝 0.1초 점프 허용)으로 조작감 보정.

## 8. 핵심 시스템 설계

### 8.1 게임 루프
```js
function loop(now) {
  const dt = Math.min((now - last) / 1000, 0.05); // 프레임 독립 이동
  update(dt);   // 물리, 충돌, 스폰, 점수
  render();     // Canvas 그리기
  requestAnimationFrame(loop);
}
```

### 8.2 물리
- 중력 `g = 2400 px/s²`, 점프 초속 `-900 px/s`, 더블 점프 `-800 px/s`.
- 속도: 기본 `400 px/s` → 거리 100m마다 +15, 최대 `900 px/s`.

### 8.3 충돌 판정
- AABB(축 정렬 사각형) 충돌 사용 — 구현이 단순하고 러너 장르에 충분.
- 슬라이드 시 히트박스 높이를 50%로 축소.

### 8.4 맵 생성
- 패턴 단위(예: 가시1+젤리라인, 구멍+공중젤리, 박쥐+슬라이드 구간)를 JSON/배열로 정의.
- 난이도 가중치에 따라 패턴 랜덤 선택, 화면 오른쪽 밖에서 스폰, 왼쪽 밖으로 나가면 제거(오브젝트 풀링).

### 8.5 점수 계산
`점수 = 거리(m)×10 + 젤리 점수 + 콤보 보너스` (젤리 연속 획득 시 콤보 배율 최대 ×2)

### 8.6 데이터 구조 (예시)
```js
const player = { x:200, y:0, vy:0, w:60, h:80, jumps:0, sliding:false, hp:100, invincible:0 };
const entities = { obstacles:[], jellies:[], items:[], particles:[] };
const state = { scene:'title', distance:0, speed:400, score:0, coins:0 };
```

## 9. 단계별 구현 방안

### 프로젝트 구조
```
cookie-run/
├─ index.html
├─ css/style.css
├─ js/
│  ├─ main.js        # 초기화, 게임 루프, 씬 관리
│  ├─ input.js       # 키보드/터치 입력
│  ├─ player.js      # 플레이어 물리·애니메이션
│  ├─ spawner.js     # 패턴 기반 스폰
│  ├─ entities.js    # 장애물/젤리/아이템
│  ├─ background.js  # 패럴랙스 배경
│  ├─ ui.js          # HUD, 메뉴, 결과 화면
│  ├─ audio.js       # BGM/SFX
│  └─ storage.js     # localStorage
└─ assets/ (images, sounds)
```

### 단계별 로드맵

| 단계 | 목표 | 주요 작업 | 완료 기준 |
|---|---|---|---|
| **1단계: 프로토타입** | 달리고 점프하는 사각형 | Canvas 세팅, 게임 루프, 중력/점프, 무한 스크롤 지면, 키보드 입력 | 사각형이 점프·착지 가능 |
| **2단계: 핵심 플레이** | 장애물·충돌·HP | 장애물 스폰, AABB 충돌, 슬라이드, 더블점프, HP 감소/게임오버, 점수 | 한 판 시작~종료까지 플레이 가능 |
| **3단계: 콘텐츠** | 젤리·아이템·패턴 | 젤리/코인 배치, 파워업 4종, 패턴 시스템, 난이도 곡선 | 아이템 효과 정상 동작, 난이도 상승 체감 |
| **4단계: 아트 적용** | 비주얼 완성 | 스프라이트 시트 애니메이션, 패럴랙스 배경 3테마, 파티클/화면 흔들림 | 사각형 → 캐릭터 이미지로 전환 |
| **5단계: UI/UX** | 메뉴와 HUD | 타이틀/일시정지/결과 화면, HP바, 파워업 게이지, 모바일 터치 UI, 반응형 스케일링 | 모든 화면 전환 매끄러움 |
| **6단계: 사운드·저장** | 몰입감 | BGM/SFX, 음소거 토글, 최고기록·코인 localStorage 저장 | 새로고침 후에도 기록 유지 |
| **7단계: 최적화·QA** | 안정화 | 오브젝트 풀링, 이미지 프리로딩, 60fps 점검, 모바일 기기 테스트, 밸런스 조정 | 중급 모바일에서 55fps 이상, 치명 버그 0건 |
| **8단계: 확장(선택)** | 장기 재미 | 캐릭터 3종 선택, 코인 상점, 일일 미션, 펫 시스템 | 캐릭터별 특성 반영 |

### 단계별 상세 팁
- **1~2단계**: 이미지 없이 색 사각형으로 먼저 재미를 검증한다. 조작감(점프 곡선, 판정)이 가장 중요.
- **3단계**: 패턴 에디터를 따로 만들지 말고 문자열 맵(`"..S..J.."`)으로 간단히 정의하면 빠르다.
- **4단계**: 스프라이트는 시트 한 장 + 프레임 인덱스 방식, 이미지 `imageSmoothing`은 스타일에 맞게 설정.
- **5단계**: Canvas 논리 해상도를 1280×720으로 고정하고 CSS로 스케일하면 해상도 대응이 쉽다.
- **7단계**: 매 프레임 객체 생성을 피하고(GC 스파이크 방지), 오프스크린 화면 객체는 풀에 반환.
