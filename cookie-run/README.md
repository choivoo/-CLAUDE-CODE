# 쿠키 대탈출
HTML5 Canvas 러닝 게임. `index.html`을 브라우저로 열면 바로 실행됩니다 (빌드 불필요).
- 조작: Space/↑/W 점프(공중에서 한 번 더 = 더블점프), ↓/S 슬라이드, P/Esc 일시정지, M 음소거
- 모바일: 화면 오른쪽 터치 = 점프, 왼쪽 터치 = 슬라이드
- 테마: 마녀의 집 → 정글 숲 → 천년나무 사원 → 꽃 언덕 (거리에 따라 전환)
- 아이템: 체력 포션, 거대화, 스피드, 자석, 보호막, 폭탄, 점수 2배

## 에셋
- `assets/ginger.png`: 사용자가 제공한 쿠키 스프라이트 시트(10프레임)에서 체크무늬 배경을 제거해 투명 PNG로 만든 파일입니다.
  프레임 좌표는 `js/game.js`의 `SPR.F`에 있습니다 (0~3 달리기 / 4 더블점프 / 5 슬라이드 / 6·7 점프 / 8 충격).
  원 저작물은 데브시스터즈의 쿠키런 캐릭터이므로 **개인 학습·팬 프로젝트 용도로만** 사용하고, 공개 배포 시에는 직접 제작한 에셋으로 교체하세요.
- 베리/초코는 같은 시트를 색상 필터(`ctx.filter`)로 변형한 것입니다. 별도 시트가 생기면 `CHARS`에 연결하면 됩니다.
- 배경·젤리·장애물·사운드는 코드로 생성한 오리지널 에셋입니다.
